# Seven Senders SQS Node.js Example

A simple Node.js application illustrating usage of Seven Senders SQS Proxy with the AWS SDK v3.
Subscribing to shipment events via SQS (Node.js/@aws-sdk/client-sqs).

> For more details refer to [Seven Senders Support Portal](https://support.sendwise.de/support/solutions/articles/15000010409-subscribing-to-shipment-events-via-sqs).

## Requirements

- Node.js 18+
- npm

## Installation

```bash
npm install
```

## Credentials

Enter your Seven Senders API key in the `sqs-js-example.js` file (`accessKeyId`).

## Usage

```bash
node sqs-js-example.js

# or
npm start
```
